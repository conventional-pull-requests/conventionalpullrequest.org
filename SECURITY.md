# Security Policy

This repository contains a static website and a specification document. It has no runtime services or
user data.

If you find a security issue, for example in the GitHub Actions workflows or the published site, report
it privately through
[GitHub private vulnerability reporting](https://github.com/conventional-pull-requests/conventionalpullrequest/security/advisories/new).
Do not open a public issue. We aim to respond within 7 days.
